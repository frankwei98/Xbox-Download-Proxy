# 复现参考项目的 DNS 选路与 HTTP 重定向路径

用户要求按参考项目的实际行为实现下载加速，而不凭“反代 server”这一称呼另行定义全流量代理。源码核实其主要路径是 DNS 指定 CDN IP，部分 Xbox 下载请求先经过 HTTP 302 改写或暴露下载链接，之后客户端下载数据直接连接 CDN；Microsoft Store 使用独立的 IP 映射组。

MVP 采用这一路径，避免将 NAS 吞吐能力加入所有下载的必经链路。相应代价是服务无法直接获取直连 CDN 的完整下载进度、逐请求错误和流量；不得将 DNS/HTTP 日志或网卡总流量标为某个游戏的真实下载速度。HTTPS、IPv6 与现网协议兼容性仍需单独验证。
