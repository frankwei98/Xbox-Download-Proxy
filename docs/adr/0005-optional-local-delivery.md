# 0005：可选离线下载与 Xbox HTTP 本地回传

状态：已接受，2026-10-19。

用户明确离线下载的目标是在 NAS 提前下载，再向 Xbox 通过局域网提供游戏数据；同时，只有 DNS/302 加速需求的用户应能跳过整个功能。

采用一个默认关闭的 `offlineEnabled` 开关，统一控制下载库、后台任务与本地回传。安装脚本询问并支持 `--offline yes|no`，显式选择才修改已有配置；WebUI 与 CLI 共用该设置。关闭时停止下载管理器、暂停任务并保留文件，不创建或读取下载库。后台任务可独立于加速 listener 运行，回传需要启动加速服务。切换配置前仍需停止加速服务。

保留现有完整文件检查与 `http.ServeContent`。保存原始 URL 和实际下载 URL，使用受支持 Xbox HTTP 域名的完整资源路径匹配 CDN 别名；只对含 Content ID 与版本 GUID 的不可变资源路径忽略查询签名。无文件名兜底，不开放任意磁盘目录，不向 Xbox 提供管理 token。回传限局域网 GET/HEAD，计数和日志来自实际本地响应。

启用后将 Xbox CDN DNS 指向 NAS；缓存未命中先沿用既有 HTTP 别名重定向，最终别名通过独立上游 DNS 或指定 CDN IP 转发，防止指回本机循环。代价是该模式未命中的数据也会流经 NAS。关闭开关恢复已有 DNS/302 行为，DNS 缓存可能延迟生效。

HTTPS 继续透传，不终止 TLS 或替换证书。由于 DNS 按域名而非协议分流，该功能要求保留 TLS 监听，避免破坏同域名的 HTTPS 请求。首版不包含 Store 回传、任意目录导入、边下载边回传、自动游戏清单获取或内容哈希验证。真实 Xbox 完成下载仍需实机验收。
