# 0004：服务端离线下载与文件系统容量

状态：已接受，2026-10-18。

用户要求在原 MVP 基础上增加离线下载和存储空间显示。采用 URL 后台下载任务，不引入账号登录、商店抓取、安装或向 Xbox 回传数据。

下载管理器独立于 DNS/HTTP/TLS 加速服务：Web/API 运行时即可工作。CLI 与 WebUI 共用认证 API。最多两个并发任务，任务和文件持久化到下载库，重启后运行/排队任务暂停；同一下载库使用进程级文件锁避免多实例同时写入。

续传核对实际文件长度，使用 Range 与源站 ETag 或 Last-Modified 的 If-Range；缺少可靠标识或服务器忽略 Range 时重新下载。每次连接与重定向只允许公网目标，已配置的 Xbox/Store IP 用于实际连接，HTTPS 保留目标域名和证书校验。

容量使用 Linux/macOS 的 statfs，针对下载目录的文件系统展示。下载前检查已知大小，接收数据期间检查剩余空间，低于 256 MiB 保留预算时暂停任务。下载文件大小单独统计，包括已取消和未完成任务。删除是用户明确操作，并同时删除文件。

完成文件通过认证 API 流式读取并支持 HTTP Range。大文件优先由 NAS 文件系统或 CLI 流式取回，浏览器兼容回退最多累积 256 MiB，避免把大型游戏整体放入浏览器内存。
