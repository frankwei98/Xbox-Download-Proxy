# MVP 设计讨论

## 已确认边界

- 产品形态：CLI + WebUI，核心是网络优选和下载加速代理工具。
- 服务端运行平台：Linux、macOS；NAS 是主要使用场景之一。
- 下载客户端：Xbox 主机、Windows Xbox App、Microsoft Store。排除 Windows 服务端不代表排除 Windows 下载客户端。
- 部署网络：只考虑家庭局域网；MVP 不支持公网 VPS 接入。
- 目标网络：中国大陆。
- MVP 平台范围：Xbox 与 Microsoft Store。
- 行为基线：独立实现，参考上游现有 Xbox / Microsoft Store 下载加速行为；不要求游戏下载数据全部经过 NAS。
- 数据路径：DNS 将下载域名指向指定 CDN IP；需要改写或显示 Xbox 下载链接时，先进入服务端 HTTP 重定向，再由下载客户端直连 CDN。
- 候选来源体验：参考上游提供预设在线候选 IP 源、分组选择、下载缓存、筛选测速与手动应用指定 IP；不要求用户自行寻找所有候选 IP。
- 交付方式：Linux/macOS 原生可执行文件，同时提供 Linux Docker 镜像。
- 开发基础：用户明确要求 MVP 前直接使用 master。仓库起点为空，无提交、远端或上游。

## 用户确认的功能闭环

候选源加载 → 地区/运营商搜索筛选 → 测速排序 → 手动应用 IP → 启动 DNS/HTTP 服务 → 查看请求日志及 Xbox 下载链接。

MVP 不包含硬盘格式化/分区工具、商店商品目录、向主机回传安装游戏、持续自动重选或既有 DNS 服务集成。用户随后扩展范围，要求增加离线下载和存储空间显示，见 [离线下载决策](adr/0004-offline-downloads.md)。README 必须明确端口要求、冲突处理及停止服务后的客户端 DNS 恢复方法。用户在实现完成后自行进行 Xbox / Microsoft Store 实机测试。

## 实现方案

- Go 标准库单服务，内嵌 HTML/CSS/JavaScript；CLI 和 WebUI 共用带 Bearer token 的 HTTP 管理 API。没有独立的前端构建依赖。
- 交付 Linux/macOS amd64、arm64 可执行文件与 Linux Docker 构建配置。
- 配置及 token 使用独立文件，配置原子保存。监听期间拒绝整份配置更改；应用指定 IP 会保存配置并停止服务，随后由用户重新启动。
- DNS 使用 UDP/TCP 53，对下载域名执行 A 映射及可选空 AAAA 答复；其他查询转发到显式配置的上游 DNS。绑定失败会关闭本次已创建的其他监听器。
- HTTP 80 只处理已支持的下载域名重定向，不提供任意反代。保留请求路径和查询参数。
- 可选 TLS 443 按 ClientHello 中的已知下载域名，原样转发到该组指定 IP 或原域名的上游 DNS 结果；不生成 CA、不解密、不对 HTTPS 改域名。这是兼容性处理，不是把 OpenWrt 的 80 端口规则扩展到 HTTPS。
- 默认候选源引用参考项目公开 GitHub 文本列表 URL；本仓库不附带其源码或 IP 表快照。支持替换 HTTPS 来源和手动导入；下载失败使用已有缓存，无缓存时尝试 DNS 发现并提示范围有限。
- global/cn1 配置公开 Xbox 测试资源 URL；cn2/store 需要实际下载 URL，避免依赖作者商店 API。Microsoft Store 的 DNS 指定 IP 功能不依赖测试 URL。
- 测速直连指定 IP、保留原 Host 与 HTTPS 证书校验；禁用重定向与压缩。每轮最多 128 个候选，默认并发 2、单节点 5 秒及 10 MiB 上限，支持取消。
- 首包延迟是取得 HTTP 响应头所用时间，包含连接；速度展示 MiB/s，API mbps 为十进制 Mbit/s。实际下载数据由客户端直连 CDN，不展示伪造的游戏下载速度。
- 运行日志只保留内存中最近 500 条，不向作者或其他后端上传。只有开启显示链接时记录完整 Xbox HTTP URL；HTTPS 不可见具体下载路径。
- 不修改宿主 DNS、hosts、防火墙或客户端设置；管理入口用于可信 LAN，随机 token 首次生成后保存在数据目录。

## 验证边界

自动化验证覆盖 DNS、HTTP、测速、候选缓存、管理接口和配置持久化，并进行竞态检测、浏览器交互与四平台交叉编译。Docker daemon 可用时才能完成镜像构建与启动验证；真实 Xbox / Store 下载及大陆 CDN 收益由用户自行验收。

## 截图与源码核对

用户提供的 v3 截图显示 DNS 与 HTTP(S) 服务开关、分组指定下载 IP、显示 Xbox 下载链接，以及网卡流量。按所检查的上游 3.0.0.65 源码，HTTP(S) 是 80/443 监听器的总开关，不代表全游戏下载流量经过它。底部上下行来自所选网卡的系统计数，不是代理专属流量；本产品若显示同类指标，应明确标注统计口径。

源码包含核心本地实现。作者云 API 参与部分商店数据、测试链接取得与数据上报，不是本地 DNS/302 的代理核心。本产品不默认继承这些作者后端依赖；Microsoft Store 测速资源的替代取得方式仍需设计。
