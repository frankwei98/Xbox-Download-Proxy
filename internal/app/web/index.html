使用帮助

将服务部署在局域网主机上，为 Xbox、Windows Xbox App 或 Microsoft Store 下载客户端提供网络优选。

01

设置下载客户端

在 Xbox 或 Windows 设备的网络设置中，将 DNS 服务器改为本页显示的局域网 IP。客户端和加速服务端需要连接同一局域网。

服务端局域网 IP—
02

检查端口占用

确保 NAS 或主机上的下列端口可供此服务使用。TLS 监听可按需关闭。

  • DNS53 UDP + TCP
  • HTTP80 TCP
  • TLS443 TCP
03

了解工作方式

停止服务后，请在下载客户端的网络设置中手动将 DNS 恢复为自动获取。本工具不会修改宿主机的 DNS 配置。HTTPS 请求保留原始域名和证书，本服务不解密 HTTPS，也不是覆盖所有流量的全流量反向代理。
